# Oque é o Node?

Node é um software de código aberto, que permite a execução do JavaScript fora do navegador Web.

# Single-thread X Multi-thread

- Single-thread: cria uma pilha com as funções chamadas e executa uma por vez, mesmo
que elas sejam concorrente.

- Multi-thread: Executa as ações paralelamente, independentes se estas são concorrentes.
